Product Catalog Import

⚠️ Admin-only tool — this is not part of the customer/employee app flow. Don't link to this page from the main app, and consider deleting it (or restricting it) before you submit/deploy for real. Anyone who opens this page and is signed in can currently write to the product catalog.

Upload a CSV with columns: barcode,name,category,price,weight_grams. See products-template.csv for an example — open it in Excel/Sheets, edit it with your own products, save as CSV, and upload here. Weight is required for the employee's scale-verification step, so don't leave that column blank.
